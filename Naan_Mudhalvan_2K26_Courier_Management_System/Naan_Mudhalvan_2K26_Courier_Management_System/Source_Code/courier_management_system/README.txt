COURIER MANAGEMENT SYSTEM – SETUP

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy courier_management_system to C:\xampp\htdocs\
4. Open http://localhost/phpmyadmin
5. Create/import Database/database.sql
6. Open http://localhost/courier_management_system/
7. Register a customer and test booking/tracking.
