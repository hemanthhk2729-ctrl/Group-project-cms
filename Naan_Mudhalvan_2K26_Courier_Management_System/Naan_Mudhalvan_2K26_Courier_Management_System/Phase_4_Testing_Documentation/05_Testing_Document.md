# Phase 4 – Testing Documentation

## Test Cases

| Test ID | Test Case | Expected Result |
|---|---|---|
| TC01 | Register with valid data | User account created |
| TC02 | Register with existing email | Error shown |
| TC03 | Login with valid credentials | Dashboard opens |
| TC04 | Login with wrong password | Error shown |
| TC05 | Book courier with valid data | Courier created |
| TC06 | Track valid tracking number | Courier status displayed |
| TC07 | Track invalid number | Not-found message displayed |
| TC08 | Logout | Session destroyed |
| TC09 | Empty required fields | Validation error |
| TC10 | Admin views courier list | Courier records displayed |

## Acceptance Criteria
The system is considered successful when customers can register, book and track parcels, while authorized staff can manage courier records and status updates.
