# Naan Mudhalvan 2K26 – Group Project
## Courier Management System

### 1. Project Title
Courier Management System

### 2. Problem Statement
Manual courier booking and tracking can cause data duplication, difficulty in tracking parcels, delayed status updates and poor record management.

### 3. Proposed Solution
A web-based Courier Management System will manage customer registration, courier booking, parcel tracking, delivery staff assignment, status updates and administrative reports.

### 4. Objectives
- Digitize courier booking and management.
- Store customer and courier information securely.
- Provide tracking using a unique tracking number.
- Allow delivery staff to update parcel status.
- Help administrators manage users and courier records.
- Reduce paperwork and manual errors.

### 5. Scope
The system covers customer registration/login, courier booking, tracking, admin management, delivery staff management and delivery-status updates.

### 6. Technology
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Server: XAMPP/Apache

### 7. Expected Outcome
A functional web application that provides a simple interface for booking and tracking courier parcels.

- Member 3: Backend/PHP development
- Member 4: Database & testing
